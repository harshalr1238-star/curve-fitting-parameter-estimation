# Curve Fitting and Parameter Estimation

## 1. Objective

The objective of this assignment is to find the unknown parameters `θ`, `M` and `X` in the given parametric equation of a curve.

The given points are provided in the CSV file `xy_data.csv`. The aim is to find parameter values that make the calculated curve as close as possible to the given data.

## 2. Given Curve

The parametric curve is defined using `t`, `θ`, `M` and `X`.

### x equation

\[
x = t\cos(\theta) - e^{M|t|}\sin(0.3t)\sin(\theta) + X
\]

### y equation

\[
y = 42 + t\sin(\theta) + e^{M|t|}\sin(0.3t)\cos(\theta)
\]

The unknown parameters are:

- `θ` (Theta)
- `M`
- `X`

## 3. Given Ranges

The parameters are restricted to the following ranges:

- `0 < θ < 50°`
- `-0.05 < M < 0.05`
- `0 < X < 100`

The parameter `t` has the range:

- `6 < t < 60`

## 4. Dataset

The given points are provided in:

`xy_data.csv`

The dataset contains the `x` and `y` coordinates of points that lie on the required curve.

I used Python to load the data and work with these points.

## 5. Approach

I followed these steps to estimate the unknown parameters:

1. Loaded the CSV data using Python.
2. Read the `x` and `y` values from the dataset.
3. Plotted the given points to understand the shape of the curve.
4. Defined the parametric equations using `θ`, `M` and `X`.
5. Defined an error function to compare the given points with the points generated by the curve.
6. Set the allowed ranges for the three unknown parameters.
7. Used an optimization method to search for parameter values that minimize the error.
8. Used the obtained parameter values to generate the fitted curve.
9. Plotted the original data and fitted curve together.
10. Compared the fitted curve with the given data using the error value.

## 6. Parameter Estimation

The optimization searches for values of `θ`, `M` and `X` within their given ranges.

For every set of parameter values, the curve is generated and compared with the given data.

The error represents the difference between the expected points and the predicted points.

The parameter values giving a smaller error provide a better fit to the given curve.

## 7. Result

The values obtained from my Python program are:

- **θ = 30.043636301°**
- **M = 0.0299905453**
- **X = 55.015520868**

The L1 error obtained is:

- **L1 Error = 0.30229127**

## 8. Fitted Curve

After obtaining the parameter values, I generated the curve using these values.

The final graph compares:

The fitted curve follows the original data closely, showing that the estimated parameters give a good fit to the given points.
